# 記事の書き方

このフォルダに `.md` ファイルを置くだけで、記事が公開されます。
（ファイルを追加 → GitHubに保存 → 1分ほどで本番に反映）

## ファイル名 = URL

```
straight-neck.md  →  https://ドメイン/blog/straight-neck
```

- 英数字とハイフンのみ（日本語・スペースは使わない）
- 内容がわかる短い英単語にすると、SEO上もわずかに有利です

## 記事の形

ファイルの先頭に `---` で囲んだ設定を書き、その下に本文を書きます。

```markdown
---
title: 記事のタイトル
date: 2026-07-14
category: 姿勢
parts: [neck, thoracic]
excerpt: 一覧に表示される2行程度の要約。
source: https://note.com/xxxx/n/xxxx
---

本文をここから書きます。
```

### 設定項目

| 項目 | 必須 | 説明 |
|---|---|---|
| `title` | ○ | 記事タイトル |
| `date` | ○ | `2026-07-14` の形式。新しい順に並びます |
| `category` | | 「姿勢」「腰痛」など。記事の上部に表示されます |
| `parts` | | **3D骨格モデルと連動**。指定した部位をタップするとこの記事が出ます |
| `excerpt` | | 一覧ページに出る要約。省略すると本文冒頭が使われません（書くことを推奨） |
| `source` | | note等の元記事URL。記事末尾にリンクが出ます |

### `parts` に使えるID

**骨格の部位（青い点）**
`neck`（首）/ `shoulder`（肩）/ `elbow`（肘）/ `wrist`（手首）/ `thoracic`（胸椎）/
`core`（体幹・腹圧）/ `lumbar`（腰）/ `hip`（股関節）/ `knee`（膝）/ `ankle`（足首）

**全身にかかわるテーマ（琥珀色の光）**
`nutrition`（栄養・消化）

複数指定できます → `parts: [lumbar, core, hip]`

> 栄養の記事には `nutrition` を入れてください。3Dモデルのお腹の位置にある琥珀色の光、または「全身にかかわるテーマ」のボタンから辿れるようになります。

## 本文の書き方（Markdown）

```markdown
## 見出し（大）
### 見出し（小）

普通の文章です。空行を1つ入れると段落が変わります。

**太字** で強調できます。

- 箇条書き
- 箇条書き

1. 番号つき
2. 番号つき

> 引用や、特に伝えたい一文

[リンクの文字](https://example.com)

| 表 | の | 見出し |
|---|---|---|
| 内容 | 内容 | 内容 |
```

## noteの記事を移す場合

1. noteの記事を編集画面で開き、本文をコピー
2. このフォルダに `.md` ファイルを新規作成
3. 上の「記事の形」の設定部分を書く
4. その下に本文を貼り付ける
5. 見出しの行の先頭に `## ` を付ける（noteの見出しは自動変換されないため）

`source:` にnoteのURLを入れておくと、記事末尾に「初出」リンクが表示されます。

## 注意

- 医療・健康の内容には、記事末尾の免責文（「一般的な情報提供を目的としたもの」）を残してください
- 断定的な効果の表現（「治ります」「必ず改善します」）は避けてください
